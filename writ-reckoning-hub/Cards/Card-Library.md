# Card Library

Imported TCG cards live here as reference notes, and on Atlas maps as tokens. One card = one note + one token image.

## How an import works (concept)

See `Plugins/TCG-Card-Importer-Concept.md` for the full write-up. Short version: search a card by name and game, the plugin fetches its image and data, saves the image into the vault, writes an Atlas token for it, and creates a note here.

## Naming convention (suggested)

`Cards/<Game>/<Card name>.md` — e.g. `Cards/MTG/Lightning Bolt.md`.
