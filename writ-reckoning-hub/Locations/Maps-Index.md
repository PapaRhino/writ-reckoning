# Maps Index

Atlas scenes live in this vault's `atlas-vtt/` folder. Each map below should have a note here linking to its scene, so the hub stays the table of contents and Atlas stays the table.

## How maps and tokens connect

- A **scene** is the map itself (image + grid + walls, built in Atlas).
- A **token** is a JSON file in `atlas-vtt/collections/<Collection>/tokens/` plus its image. The vault already ships starter tokens (assassin, cleric, fighter, knight, occultist, paladin, ranger, rogue, warlock, wizard).
- Imported TCG cards become tokens the same way — see [[Card-Library]] and the importer concept in `Plugins/`.
