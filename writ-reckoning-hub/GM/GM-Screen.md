# GM Screen

## Before the session

- [ ] Pull the session's maps up in Atlas and check tokens are placed.
- [ ] Re-read last session's log ([[Session-Template]]).
- [ ] Note the scenes planned and the NPCs in them ([[Character-Index]]).
- [ ] Commit and push the vault so the backup is current.

## During the session

- [ ] Log scenes and key outcomes in the session note as you go.
- [ ] Note any new NPCs, locations, or rulings to file afterward.

## After the session

- [ ] Finish the session log and write the "Next time" list.
- [ ] File new characters, locations, and cards in their indexes.
- [ ] Commit and push.
