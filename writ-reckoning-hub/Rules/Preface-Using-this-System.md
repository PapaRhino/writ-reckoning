# Preface: Using this System

Source: Writ & Reckoning Official Sourcebook V2.2 (October 2025).

- You don’t need cards.  This system will teach you how to make and use your own custom cards.  If you do want to use your own tcg cards, see our [Guide for Including Existing TCG Cards](https://docs.google.com/document/d/1KtN2nky_XDmvuH3Jd4AW4oJ6GfoE42QKUOOR7Kwp0CE/edit?tab=t.0).

- This game does require a GM and at least 1 player.  Suitable for normal TTRPG groups of around 4-7

- This game does have it’s own built in lore.  But the mechanics can be lore-agnostic.  Lore is marked in green. And you can access a [lore-building worksheet](https://docs.google.com/document/d/11HnjwOB-Sf4GKMZ4TmzWyrD-5NqmbJopAFpnADh0ohQ/edit?tab=t.0) should you want to write or change your own lore for your own worlds.
